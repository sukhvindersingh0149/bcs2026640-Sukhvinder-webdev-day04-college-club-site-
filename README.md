
# Invertis Coding Club Website

## Project Description
This is a responsive College Coding Club website
created using HTML5 and CSS3.

## Pages
1. index.html - Home Page
2. about.html - About Club and Event Table
3. registration.html - Student Registration and Volunteer Forms
4. contact.html - Contact Details and Message Form

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code

## Features
- Responsive navigation bar
- Student registration form
- Volunteer application form
- Contact form
- Accessible HTML event table
- Native HTML form validation
- SVG favicon

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. You can also use the Live Server extension.
